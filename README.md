# Organization Defaults

This repository holds the organization profile and the default issue forms.

## Contents

- [Issue Forms](./.github/ISSUE_TEMPLATE)
- [Organization Profile](./profile/README.md)

## Inheritance

A repository uses the default issue forms only when it does not contain a `.github/ISSUE_TEMPLATE` directory.

A repository that contains a `.github/ISSUE_TEMPLATE` directory uses none of the default issue forms or their configuration.

The organization profile is displayed on the organization page and is not inherited.
